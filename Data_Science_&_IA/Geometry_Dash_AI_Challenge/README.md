# Geometry Dash AI Challenge

Este repositório faz parte de um experimento para comparar as capacidades de diferentes modelos de IA na criação de jogos.

O desafio foi simples: pedir para **ChatGPT, Gemini e Claude** criarem uma versão jogável inspirada em **Geometry Dash** utilizando **Python e Pygame**, com o mínimo possível de intervenção manual. Após a geração do código, cada projeto foi executado e avaliado com base em critérios como:

* Funcionalidade
* Fidelidade ao jogo original
* Qualidade do código
* Jogabilidade
* Facilidade de execução

O objetivo não é determinar uma vencedora absoluta, mas explorar as diferenças entre as abordagens de cada IA quando enfrentam o mesmo problema de desenvolvimento.

O resultado completo do experimento pode ser visto no vídeo publicado no YouTube.

## Tecnologias

* Python
* Pygame

## Objetivo

Descobrir qual IA consegue criar a melhor versão de Geometry Dash a partir de um único prompt.
